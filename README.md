## Requirements
- [Godot Engine](https://godotengine.org/download/windows/) (matching major version 4.5.x)

## Clone the Repository
git clone <REPO_URL>  
cd <REPO_FOLDER>

## Run the Game (Editor)
1. Open Godot  
2. Import → select the project folder (`project.godot`)  
3. Open the project  
4. Start the game with F5 (Play)

## Contributing

There are several things to consider when contributing to this project:
1. [Directory Structure](https://github.com/Tiltnick/ip2gd/wiki/Architecture#directory-structure)

## CI/CD Pipeline Export

The project is exported via a CI/CD pipeline after a pull request to the `main` branch has been approved by two people.

## Troubleshooting
